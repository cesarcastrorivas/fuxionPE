# fuxionPE

Este proyecto contiene un ejemplo sencillo de una aplicaci\u00f3n web en Python usando Flask.
La aplicaci\u00f3n permite ingresar dos n\u00fameros, sumarlos y mostrar el resultado.

## Requisitos
- Python 3
- Dependencias listadas en `requirements.txt`

Instala las dependencias con:
```
pip install -r requirements.txt
```

## Uso
Ejecuta la aplicaci\u00f3n con:
```
python app.py
```
Luego abre `http://localhost:5000` en tu navegador y podr\u00e1s ingresar dos n\u00fameros para sumarlos.
